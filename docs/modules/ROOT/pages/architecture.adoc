== Pipeline Stages

=== Reader

The reader (`smd::cl::reader`) parses Common Lisp source text into a datum
tree.  It parses data only and does not classify special forms — all lists
are initially treated as data.

Source: `src/smd/cl/reader/`

=== Core

The core AST (`smd::cl::core`) is the typed tree the elaborator produces
and the evaluator consumes: `core_if`, `core_lambda`, `core_progn`, and the
rest of the elaborated special-operator set, plus `core_call` for
everything else.

Source: `src/smd/cl/core/`

=== Elaborator

The elaborator (`smd::cl::elaborator`) walks the datum tree and classifies
Common Lisp's special operators into the core AST.  This is the layer that
knows the language; the reader upstream of it does not.

Source: `src/smd/cl/elaborator/`

=== Eval

The evaluator (`smd::cl::eval`) is a small-step machine, not a recursive
tree-walker: `machine::step` is the coalgebra, `step_status` says whether a
state is final, and a frame stack folds results back as it pops.  `builtin`,
`environment`, `heap`, `outcome`, and `value` are the machine's supporting
types.

Source: `src/smd/cl/eval/`

=== Sender Backend

The sender backend (`smd::cl::sender`) evaluates programs via Beman
Execution senders (`sender_v`'s vocabulary aliases, `machine_sender`,
`run_sender`), making the execution plan a first-class sender graph.

Source: `src/smd/cl/sender/`

== Symbol

The symbol table (`smd::cl::symbol`) interns names into stable
`symbol_id`s (decision D12); identity is id comparison, not string
comparison, and a symbol carries a value slot, a function slot, and a
macro slot.

Source: `src/smd/cl/symbol/`

== Foundation

The pipeline stages share two layers of foundation utilities.
`smd::kit::foundation` is the language-agnostic substrate extracted in step
R8 (`static_vector<T, N>`, `arena_box<T>`, `result<T>`, the `functor` /
`applicative` / `monad` typeclass objects); `smd::cl::foundation` adds what
is specific to this front end, forwarding to `kit` wherever the two share a
type.

Source: `src/smd/kit/foundation/` and `src/smd/cl/foundation/`
